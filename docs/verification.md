## 故障定位

| 现象 | 排查顺序 |
| --- | --- |
| 初始化或发现失败 | 实例运行状态 → URL 可达性 → 传输类型 → 令牌/请求头有效期 → 工具 schema 支持 |
| 只有内部回环 URL | 这是云电脑内部地址，需要实际对外接入配置或已有安全网络路径 |
| `exposed` 为 0 | 查看交付版本的工具名称，与允许名单匹配；用精确 `allowTools` 配置经检查的工具 |
| 参数不匹配 | 重新读取 `npm run tools`，按该版本 schema 修改本地参数 JSON |
| 调用超时 | 先检查云端实际状态；不直接重发点击、输入等操作 |
| ChatGPT 看不到工具 | 本地 doctor → Tunnel doctor → 账号/工作区权限 → 安装并选中该连接 |
| 切换配置没有生效 | 重启桥接和客户端；当前会话的工具清单在连接时固定 |

当前实现不自动刷新 OAuth 或重连，也不代理资源、提示词订阅、服务器主动采样或长任务协议。聚焦同步工具调用，便于客户理解并按自己的部署扩展。

首次截图检查使用本地 `allowTools: ["aiengine__screenshot"]` 精确开放截图工具，未放开 shell 或文件操作。服务聚合可能为工具名称添加前缀；请按实际清单配置，不通过去前缀自动扩大权限。首次连接检查的截图和连接信息保存在本地忽略目录。后续 Power BI 案例仅公开经检查、展示模拟数据的专用演示截图；不公开客户桌面内容、完整网关地址和原始响应。

后续真实 Demo 通过显式 `npm run demo` 临时允许 shell、write_file、read_file，未修改普通桥接默认权限。它使用固定 PowerShell 脚本驱动云电脑 Chrome 和记事本；源码见 `remote/`。浏览器证据由 CDP 在页面执行后捕获，桌面证据由 Windows 在文本校验后捕获，均通过 MCP 文件工具取回。
