# 两个客户演示任务

运行前：连接您自己的无影 MCP，检查 `tools/list`，将 profile 设置为 `interactive` 并重启连接。模型依据实际 schema 生成参数。若缺少工具，停止该步骤并说明，不调用本机工具冒充无影结果。

## 1. Browser Use：从页面观察到操作验证

可直接向已连接的 AI 客户端发送：

> 请使用 wuying-demo 连接中的浏览器工具，在无影云电脑的浏览器打开 https://example.com。先读取当前页面结构，再找到并点击 “Learn more” 链接，最后报告实际打开的页面标题和地址，并提供截图（如果当前端点支持）。只执行这些浏览操作；不要登录或提交表单。如果工具不可用，请明确说明。

观察顺序：导航 → 当前页面快照 → 使用快照中的最新元素引用点击 → 再次观察 → 返回实际结果。不要复用导航前的元素引用。

验收：网页确实在目标云电脑打开；标题/地址来自工具返回；点击前后有可核查的观察结果。网络受限或网页变更时如实报告。

## 2. Computer Use：在真实桌面应用中输入

先在演示云电脑打开一个空白文本编辑器，然后发送：

> 请使用 wuying-demo 的桌面工具查看当前屏幕和窗口，找到我已打开的空白文本编辑器。确认后在其中输入 “Hello from Wuying MCP”，再截图验证。不要保存文件，不关闭其他窗口，不运行终端。如果无法确定目标窗口或坐标，请停下来询问。

观察顺序：截图 / 窗口列表 → 确认编辑器 → 激活并定位输入区 → 输入文本 → 新截图验证。

验收：文本出现在真实云电脑窗口中；截图与输入操作对应同一会话。桌面坐标来自当前屏幕，不能使用浏览器快照的元素引用代替。

## 展示时的讲解

“模型负责理解目标与选择下一步，无影提供正在运行的浏览器、桌面和应用。每次操作都有真实状态返回，客户可以看到 AI 正在做什么，也可以接管继续完成。”

以上是任务提示词和验收方法，不是预先生成的执行结果。Windows、Ubuntu 等环境的实际工具名称和应用可用性，由所连接实例决定；云手机不在本示例已验证范围内。
